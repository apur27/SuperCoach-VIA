*Statistic definitions from the AFL website

*The table below details which stats are available for which seasons. From 2011, all categories are complete.

*The second table details exceptions to the first

*These statistics are *not official*, and will contain errors, both in the original source and arising due to the transcription process.

*Obvious errors in the source have been corrected where observed e.g a non-ruckman being attributed a large number of hitouts when the regular ruckman has none.

*In most cases, games where the stat is missing will not count when calculating average per game. e.g Kevin Bartlett played 403 games, but five games had no behinds recorded.

Hence 398 games is used to determine his behinds per game average.
