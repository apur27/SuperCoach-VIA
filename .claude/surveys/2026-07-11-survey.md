### F1 — Real 2025 game missing from matches_2025.csv; match dedup key can collapse simultaneous games  [severity: CRITICAL] [class: 5]
- Evidence (all measured 2026-07-11):
  - Per-team H&A count, matches_2025.csv: Port Adelaide 22, Collingwood 22, all
    16 others 23; the only round both lack is round 2 → the missing game is
    PA v Collingwood R2 2025. 2024 control: all 18 teams exactly 23.

  - Simultaneous-kickoff `(date, round_num)` pairs: 2022→11, 2023→6, 2024→9,
    2025→0, 2026→0 — implausible scheduling; consistent with dedup collapse.
  - Mechanism: `scrapers/game_scraper.py:686` key `f"{date}_{round_num}"` and
    `:699` `drop_duplicates(subset=['date','round_num'], keep='last')` — no venue,
    no teams. Forward-only delta (`game_scraper.py:680`, skip `<= last_processed_date`)
    means a lost game is never re-fetched; `audit_match_rounds` only WARNs
    (`refresh_data.py:273-283`). No gate covers match-file completeness
    (phantom_row_validator scans player CSVs only).
- Impact: every consumer of matches_2025.csv (team analysis, H2H ledgers, season
  aggregates) computed on an incomplete corpus; published team-level numbers may
  be wrong; loss is silent and permanent.
- Owner: Scientist.
- Recommended outcome: dedup key includes venue + both team names; the missing R2
  2025 row restored; a deterministic completeness gate (per-team games-per-season
  vs expected) added to the refresh path so this class can never pass silently.
- Effort: M · Impact-per-day rank: 1 · **ESCALATED to human** (published numbers wrong).

## Anti-pattern list (standing)
- Never trust an LLM sum; re-measure disputed numbers in pandas before acting.
- Never verify by exit code; re-read the file content after any write.
- Never `git add .`; stage by explicit allowlist.
- Never hand-edit anything under `data/` or a generated table body.
- Never let a Pass-1 PASS stand in for Pass-2 clearance.
- Never soften an upstream caveat when translating numbers into prose.
- Never run the refresh before round settlement (Tuesday 8 PM UTC).
- Never push to `main` from parallel agents; serialize through one committer.
- **NEW (F2/F4 evidence): never select a "latest" artifact by mtime** — encode
  round + timestamp in the filename and parse it, or pass the path explicitly;
  mtime is meaningless on fresh checkouts and under concurrent writers.
- **NEW (F3 evidence): never record a gate verdict for an artifact the gate did
  not actually inspect** — verdict-recording loops must be keyed to the gate's
  own coverage list, not to a file glob.
