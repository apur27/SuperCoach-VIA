Skeptic blocked the Round 21 `docs/afl-insights.md` tactical note (line 28) across **two** BLOCK passes on the same sentence — the first three patterns were fixed and passed, but the fixed sentence still carried two further findings in its closing clause. Lesson: after fixing a Skeptic BLOCK, re-read the *entire* sentence again, not just the clause you just edited — a clean opening clause can still be attached to an unfixed closing clause.

1. **Identity asserted from correlation.** A strong r (even +0.75) supports "strongly associated" or "strongest correlate of," never "the same skill expressed twice" / "is" / "are identical." Correlation coefficients bound the *strength* of a relationship, not its *mechanism* or *sameness*.
2. **Variable substitution.** Don't cite a correlation between variables A and B, then draw a conclusion about variable C (e.g. citing contested-possessions-vs-clearances r, then concluding something about "midfield disposal volume" — a third variable the cited stat never measured). Check that the noun phrase in the conclusion clause is literally one of the two variables in the cited r.
3. **Unscoped dataset-wide superlatives.** "The clearest predictor" / "the dataset's cleanest evidence" / "the clearest example" claims global superlative status. Before writing any superlative, check whether the source doc actually supports it — for a "clearest example" claim about a specific player, check whether a *ratio* between the two leaderboards (e.g. clearances-per-contested-possession) is computable from the source's top-5 tables. It often isn't: a player who leads both raw counts (rank 1 on each leaderboard) is not verifiably the best *converter* of one into the other if rival players sit outside the shown top-5 on one axis (their true value is unknown from the doc) — don't infer a ratio the source doesn't publish. Safe fallback: state the plain fact that the player is rank 1 on both tables; don't characterise that fact with a superlative adjective.
4. **Causal predicate over correlational evidence.** Phrases like "translating directly into," "driving," "producing," "converting X into Y" assert a causal mechanism. A correlation plus one player topping two leaderboards establishes neither direction nor mechanism. Use "association," "pairing," or "leads both" — never a verb that implies one stat causes the other.
5. **Window mismatch.** Per-game season-to-date averages (e.g. rounds 1–20 aggregates) are not "this round"'s figures. If the sentence sits under a "Round N — Week in Review" header, double-check every number's actual aggregation window against the methodology line before attaching a round-specific qualifier to it — the header's round number is not evidence that a cited stat is scoped to that single round.

**How to apply:** before finalizing any "Tactical note" or similar interpretive sentence built on a correlation figure, re-read the source doc's correlate listings and leaderboard tables and ask (a) am I claiming identity instead of association, (b) does my conclusion clause name the same variable that's in the cited r, (c) is my superlative scoped to what the source actually supports, (d) does any verb imply causation/mechanism, (e) does any time-window qualifier ("this round," "this week") match the actual aggregation window of the number it modifies. See [[datasentinel_gate_traps]] for the sibling DataSentinel-side trap (methodology footnotes restating tagged numbers) that fires on the same paragraph.
